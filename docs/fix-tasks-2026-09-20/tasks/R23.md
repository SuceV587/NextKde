## 问题
`shell/desktop/modules/common/AppIcon.qml:39-51`、`QuickSearchWindow.qml:278-288`、`DockIcon.qml:659` — dock/桌面/搜索结果里每个图标都 `IconImage`→`layer.enabled`（渲染到 FBO 纹理）→`ShaderEffect` 再画一次。几十上百个图标 = 同数量 RGBA FBO + 每帧两次光栅化，批处理被 FBO 切换打散。而 `icon_effect.frag` 只做 1 次采样+luma+mix——极便宜，多数情况（默认 color 模式）根本不需要它。

## 改动点
- `IconImage` 的 `layer.enabled`/`ShaderEffect` 改为条件启用：`mode==="color" && saturation===1 && !tintEnabled` 时直通显示，跳过 shader。
- 参考先例 `DeskCenterWindow.qml:345`（`layer.enabled: mode!=="color"`）。
- 同步处理 QuickSearch/Dock 的同类图标路径。

## 验证
- 默认 color 模式下图标仍正常着色；切到非 color 模式效果生效。
- QSG 显存/FBO 数对比（`QSG_VISUALIZE` 或 renderdoc）。

## 审查要点
- 条件判断覆盖所有需要 effect 的组合（grayscale/tint/desaturate）。
- 切换 mode 时 layer 正确开关无残影。
