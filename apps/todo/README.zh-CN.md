# KOS 待办

KOS 待办是独立的 Qt Quick 任务管理应用。它通过带版本的本地 PIM 协议与
KOS 日历共享数据，但不会导入日历或 Shell 的代码。

## 当前状态

第一阶段提供可独立构建的应用和支持键盘操作的收件箱原型。在本地 PIM 服务
接管持久化与提醒前，原型任务有意只保存在内存中。

## 构建

```bash
cmake --preset todo-dev
cmake --build --preset todo-dev
```

可执行文件位于 `.build/todo-dev/apps/todo/`。

## 计划范围

- 清单、任务、子任务、优先级和手动排序。
- 截止日期、重复规则、完成历史和提醒。
- 收件箱、今天、计划、已完成、筛选和搜索。
- 通过服务与日历共享事务型本地持久化。

首版暂不包含云端协作和第三方任务账户。
