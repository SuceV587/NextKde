# KOS 待办

KOS 待办是独立的 Qt Quick 任务管理应用。它通过带版本的本地 PIM 协议与
KOS 日历共享数据，但不会导入日历或 Shell 的代码。

## 当前状态

应用现在可以独立构建和安装。任务与清单由共享的本地 PIM 服务持久保存。
界面提供收件箱、今天、计划、已完成和自定义清单视图，并支持快速添加、任务
编辑、完成状态、截止时间、优先级、重复规则、提醒和备注。

## 构建

```bash
cmake --preset todo-dev
cmake --build --preset todo-dev
```

可执行文件位于 `.build/todo-dev/apps/todo/`。

## 第一版边界

- 已包含：持久化清单与任务、筛选视图、截止时间、完成状态、iCalendar
  优先级、重复规则、提醒、备注和键盘快捷键。
- 服务契约已保留父任务 ID 与手动顺序，后续补充子任务和拖拽排序界面时无需
  迁移存储。
- 暂缓：搜索、创建子任务、拖拽排序、清单编辑/删除、完成历史界面、云端协作
  和第三方任务账户。

日历和待办是两个独立应用，只共享带版本的 `Kos.Pim` 服务契约。详见
`docs/PimArchitecture.md`。
